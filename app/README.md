# 日程挂件 Demo

按 `需求_v1.3.md` 搭的最小可运行 Demo：W1 桌面挂件 + W2 下拉窗 + 系统托盘。

## 运行

- 双击上一级目录的 `启动日程挂件.cmd`
- 或者在 `app` 目录下运行 `npm start`
- 刚拉下代码时先运行 `npm install`，会顺带下载 Electron 本体

## 主界面设计预览

- 当前完成项和后续体验事项见 [项目进度](../项目进度.md)。`../设计/便当盒主界面提案.html` 记录已采用的日历布局和配色；2026-10-10 已迁移到软件。
- 主界面为纯白背景，周末表头和日期采用明亮蓝紫色；日期字号为 17px。空白周随宽度缩放并保留至少 56px 高度，有日程时按实际条数增高，日程条之间留 5px 间距。
- 打开 `../设计/主界面预览.html`，可以查看示例日程，尝试新建、编辑、完成和确认提醒。预览中的改动只存在内存中，刷新后恢复，不接触实际日程数据。
- 只有用户明确需要更新预览时，才在 `app` 下运行 `node scripts/preview-main.js`；`npm run preview:main` 会同时启动本地预览服务。独立 HTML 保留最近一次生成的版本，可能落后于实际软件。
- 主界面是一张竖版圆角卡片：提醒位于月历上方并以卡片堆显示，滚轮切换顶层、点击展开或收起；悬停日程时，详情在月历下方展开，点击后保持显示并提供操作。
- 主窗口高度随内容变化：悬停详情和展开提醒时，窗口底边随动画向下延伸，收起后缩回；正常情况下日历保持原位。到达屏幕工作区底部时才限制高度，让内容滚动。填写弹窗和设置页会留出足够的操作空间。
- 两种新建方式：直接单击日历的一天，或从日期 / 空白处拖选区间，松开鼠标后打开填写窗口并填好日期；日历上方「新建日程」按钮直接填写，当前月默认今天、其他月份默认该月 1 日。拖选时可按 Esc 或右键取消，已有日程条仍用于查看详情。顶部空白处拖动窗口。
- 月份切换、“回到今天”和“新建日程”整排位于标题下方、提醒和日期网格之前，独立于日历滚动区域；月份行数或日程数量变化时，按钮位置保持不动。
- 新建 / 编辑弹窗默认显示标题、并排日期和两行备注；颜色与提醒按需展开，置顶在同一排。高度按内容伸缩，底部保存与取消始终可见，空间不足时仅中间区域滚动。标题旁的小色条在未填写时显示“预览”，填写后实时显示日程标题。
- 日期、拖选以及主界面原来显示小手的按钮、日程条、提醒卡片、弹窗和设置控件，统一使用用户提供的圆润箭头：白色主体、灰蓝细描边，尺寸为 14.52px，热点为 (3, 1)。文字输入与等待状态保留各自的光标。
- 新用户的主窗口默认宽 480px，高度由内容决定；已有用户保留保存的位置和宽度。
- 吸附后移开约 100ms 开始收起，收起动画约 160ms、展开约 180ms，先快后慢；鼠标返回正在自动收起的窗口时可以从当前位置展开。填写、设置与拖动时仍阻止自动收起。
- 设置采用日历上方的磨砂浮窗，点击外侧空白、关闭按钮或 Esc 关闭，带短缓动。外观、提醒、通用分开排列；日程条字号与高度直接显示，上方留白适当缩减。高度随内容变化，空间不足时只滚动中部，底部操作持续可见。

## 桌面挂件（2026-10-20 显示方式改造）

- 保留桌面 HTML 的蓝紫色周末、薄荷绿柔光“今天”圆、半透明底板和深蓝灰日程条文字。按日程数量增加高度，悬停详情在下方缓动展开，原生窗口顶边保持原位。新显示方式暂未接入背景磨砂。
- 在“设置 → 外观”调整玻璃不透明度、挂件宽度、日期字号、磨砂强度、玻璃底色和文字颜色。拖动时预览，完成调整后保存；提供恢复默认，日程条字号和高度始终显示。“通用”内可钉住 / 解锁、重置位置和调整开机自启。
- 默认白色底板不透明度 14%、宽度 420px、日期 17px。磨砂改为 0–40 的滑块，步长 1，0 为关闭，旧 `blur` 数值原样回填；悬停“磨砂强度”旁的线条问号，可查看实际桌面磨砂尚未接入的说明。日期字号独立于日程条文字，默认值与范围集中于 `renderer/shared/appearance.js`。
- `main/w1.js` 的 Electron 窗口始终隐藏，以离屏方式绘制。`main/desktop-surface.js` 把网页帧交给独立的 Win32 分层窗口，圆角由逐像素透明度表示。解锁时这个原生窗口支持拖动；钉住时它成为现存桌面壁纸容器的子窗口，并穿透点击。星尘的最新手动截图已显示图标清晰位于日历上方，并反馈“不闪了”；“显示桌面”后的保留情况尚未单独确认。
- `main/win32.js` 只查找可见且属于 Explorer 的宿主，排除隐藏旧窗口和其他程序的同名窗口。100ms 光标检查不改变层级；桌面事件和 3 秒健康检查只在关系或绘制顺序确实改变时恢复自己的窗口，不重排图标或 Wallpaper Engine。
- 100% 与进程内模拟 125% 缩放的隐藏检查通过：透明帧、自然高度、保存失败恢复、宿主销毁重建、解锁后重启定位，以及动态壁纸新增子窗口后的顺序恢复。隐藏检查不证明真实合成可见；此前两次用户均未看到日历的短测仍记录为失败。旧原生玻璃模块保留供后续研究，目前不对新显示窗口启用。

## 目录

| 目录 | 内容 |
|---|---|
| `main/` | 主进程：界面、原生桌面显示窗口、挂靠、边缘吸附、托盘、数据存储、提醒生成 |
| `preload/` | 页面能调用的接口 |
| `renderer/shared/` | 日历排版、日期、颜色，两个窗口共用 |
| `renderer/w1/` | 桌面挂件页面 |
| `renderer/w2/` | 下拉窗页面（日历、填写弹窗、设置页） |

## 数据

全部放在 `app/.data/`，不进 git：`tasks.json`、`settings.json`、`reminders.json`，以及各自的 `.bak` 备份。Electron 自己的缓存也在这里，不写到系统的 AppData。

## 自测

`npm run selftest:panel-motion`：模拟时钟和原生窗口接口，检查三侧吸附的收起等待、动画中间帧、返回反向展开、阻止条件及 3px 边缘。不会打开窗口，不代表已实测原生动画手感。结果为 `.data-selftest/shots/w2-motion-result.json`。

`npm run selftest:settings`：隐藏实际设置页面，检查不同宽高下的浮窗排版、外侧点击、焦点、分类、保存与失败恢复；桌面操作和保存接口只使用内存模拟，不控制系统鼠标或真实日程。结果为 `.data-selftest/shots/w2-settings-result.json`。

`npm run selftest:calendar-selection`：隐藏窗口检查主面板两种新建入口、跨周和反向拖选、取消操作、已有日程点击及选区保存。使用内存示例数据，不控制系统鼠标，不读写真实日程。结果为 `.data-selftest/shots/w2-selection-result.json`。

`npm run selftest:task-dialog`：隐藏窗口检查紧凑弹窗在 480px / 380px 宽度下的可见性、短窗口滚动、折叠选项的完整保存、编辑回填及保存失败重试。使用内存样例，不操作系统鼠标或真实日程。结果为 `.data-selftest/shots/w2-dialog-result.json`，同目录保存测试页面自身的截图。

`npm run selftest`：用单独的 `app/.data-selftest/` 跑一遍关键流程（悬停、钉住嵌入、新建、校验、设置页、吸附收起），截图和结果存在 `.data-selftest/shots/`，跑完自动退出。主窗口还会检查原生窗口高度、展开/收起的中间帧、日历是否被挤压、四角透明度、长备注滚动和三侧贴边；日历布局覆盖 4/5/6 周月份、不同窗口宽度及 30 条叠放。断言失败时返回非零退出码。

`npm run selftest:desktop-headless`：完全隐藏的桌面检查。使用自有隐藏宿主，不读取或改变 Explorer 窗口关系，不操作系统桌面。结果为 `.data-selftest/shots/w1-host-result.json`。加 `-- --force-device-scale-factor=1.25` 可模拟 125% 缩放，只影响测试进程。

`npm run selftest:desktop`：获准后执行的可见短测。独立挂件先显示 4 秒，再钉住 16 秒，最迟 25 秒退出。结果为 `.data-selftest/shots/w1-desktop-host-result.json`。用户在钉住阶段自行点击“显示桌面”；脚本不模拟该系统操作，不截取其他软件。`structuralPass` 只记录接口和绘制结果，`visualPass` 保持空值，等待用户实际观察反馈。

`npm run selftest:desktop-ui`：会显示挂件和设置页，检查外观、提醒、完成状态与保存。磨砂只验证设置保留，不验证实际效果。结果为 `.data-selftest/shots/w1-smoke-result.json`。旧 `w1-glass-selftest.js` 不能对新原生显示窗口运行，入口设有明确检查，避免误报。

以上可见测试都应先确认不影响用户正在进行的桌面操作。它们不涵盖多屏切换、系统重启、长内容贴近屏幕底部等完整场景。

自测入口安装专用错误处理：日志管道关闭时继续保留文件记录；未处理异常写入 `.data-selftest/shots/selftest-fatal.json` 并以失败退出，不弹出主进程错误对话框。桌面短测不会点击系统“显示桌面”或替用户收起所有工作窗口，这一步单独实测。

## Demo 里的临时做法（需求里还没定的地方）

- 提醒默认值：开始前 1 天、开始当天、结束当天
- 单日日程的「开始当天」和「结束当天」提醒合并成一条
- 改了日期后，这条日程之前没确认的提醒先去掉；错过的提醒不补发
- 桌面文字初始默认是深蓝色 `#315873`，日程条文字为深蓝灰 `#345662`；两个窗口的日程条默认高 15px、字号 10px
- 主窗口提醒堆叠在日历上方，桌面提醒标志在右上角
- 开机自启默认关闭，在托盘或设置页里打开
- 托盘菜单里的「Demo：载入示例日程」只是为了方便看效果，会追加一批示例日程
