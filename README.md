# 鱼鱼日程

Windows 桌面日程工具。桌面挂件随手看一眼，月历界面管一整个月，提醒走系统托盘。

## 功能

- **月历视图**：按月查看，跨天的日程连成一条，一眼看清。
- **日程管理**：新建、编辑、完成、置顶、删除。
- **提醒**：待确认的日程以卡片形式弹出，不打断当前工作。
- **桌面挂件**：可自由摆放，也可以钉在桌面背景层，不挡窗口。
- **主窗口**：支持吸附到屏幕顶部、左侧、右侧后收起，鼠标移上去再展开。
- **外观**：字号、配色、挂件宽度、玻璃质感都能调。
- **数据**：所有日程只保存在本机，不联网、不上传。

## 安装

下载 Releases 里的 `鱼鱼日程-x.x.x-Setup.exe`，双击安装。

> 安装包未签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，
> 点「更多信息」→「仍要运行」即可。

默认安装到 `%LOCALAPPDATA%\Programs\Little Fish Planner`，安装位置可自选。
日程与设置保存在 `%APPDATA%\鱼鱼日程\`，升级和卸载都不会删除。

## 从源码运行

需要 Windows 10/11 和 Node.js 22.12 或更高版本。

```bash
cd app
npm ci --include=dev
npm start
```

打包安装程序：

```bash
cd app
npm run dist:win      # 输出到 dist/鱼鱼日程-<版本>-Setup.exe
```

## 目录

```text
app/
├─ main/        Electron 主进程、窗口、数据与托盘
├─ preload/     页面与主进程之间的接口
├─ renderer/    桌面挂件、主界面、设置、托盘菜单
└─ assets/      图标
installer/      安装程序界面与打包配置
```
